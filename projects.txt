The modules progressively teach C++ programming, object-oriented design, memory, polymorphism, templates and the Standard Template Library.
31. CPP Module 00
- Description: Introduction to C++ and object-oriented programming.
- Technologies: C++98, compiler and Makefile.
- Concepts: namespaces, classes, member functions, standard I/O, initialization and basic object design.
- Skills: C++ syntax, classes, encapsulation and object-oriented fundamentals.

32. CPP Module 01
- Description: Explore memory allocation, references and pointers in C++.
- Concepts: stack vs heap, new, delete, references, pointers to members and switch statements.
- Skills: memory management, object lifetime, references, pointers and resource handling.

33. CPP Module 02
- Description: Learn ad-hoc polymorphism and operator overloading.
- Concepts: Orthodox Canonical Form, fixed-point numbers, constructors, copy assignment and arithmetic/comparison operators.
- Skills: operator overloading, class design, copy semantics and encapsulation.

34. CPP Module 03
- Description: Study inheritance and class relationships.
- Concepts: base classes, derived classes, access modifiers and multiple inheritance.
- Skills: inheritance, code reuse, class hierarchies and object-oriented design.

35. CPP Module 04
- Description: Explore subtype polymorphism and abstract classes.
- Concepts: virtual functions, abstract classes, interfaces, deep copies and runtime dispatch.
- Skills: dynamic polymorphism, virtual methods, abstraction and memory ownership.

36. CPP Module 05
- Description: Learn exception handling and structured error management.
- Concepts: exceptions, try, catch, throw, custom exception classes and nested exception handling.
- Skills: error handling, exception safety and robust class design.

37. CPP Module 06
- Description: Understand C++ type conversions.
- Concepts: static casts, reinterpret casts, const casts, dynamic casts and scalar conversions.
- Skills: type systems, casting, runtime type identification and safe conversions.

38. CPP Module 07
- Description: Introduce function and class templates.
- Concepts: generic functions, generic classes and template instantiation.
- Skills: generic programming, reusable code and compile-time abstraction.

39. CPP Module 08
- Description: Work with templated containers, iterators and algorithms.
- Concepts: STL containers, iterators, algorithms and custom container behavior.
- Skills: Standard Template Library, generic programming, iterators and container abstraction.

40. CPP Module 09
- Description: Apply STL containers and algorithms to more substantial problems.
- Concepts: container selection, sorting, data organization and algorithm implementation.
- Skills: STL, data structures, algorithmic problem-solving and performance considerations.
